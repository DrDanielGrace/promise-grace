Measurement records

This site's argument is that the physics is real, so a change to a simulation has to be able to prove which quantities it moved rather than assert that it moved none. Every substantial change is preceded by capturing the readouts on the live code, and followed by capturing them again.

  • The crystal growth rate, before and after the time scaling fix

    The growth rate curve was empty at every gravity because the rate was being multiplied by 1400 before integration, which moved the crystal about seven millimetres in the first frame, thirty times past the stop. Every run ended on frame one. The multiplier is gone, no physics changed, and a run now lasts 1.04 seconds at full gravity, 4.72 at a hundredth of it and 8.02 with none.

  • The crystal readouts at three gravities, before the frame was built

    Captured so that putting the simulation inside a full screen frame could be shown to have changed no numbers.

  • The audio audition

    Ninety three candidate recordings, each decoded in the browser and scored on duration, peak, RMS, DC offset, the ratio of energy below 700 Hz to energy above 5 kHz, decay to minus twenty, steadiness and loop seam. It is why a given file is in the sound folder and the others are not.

These live in the repository rather than on the site, because they are for whoever changes the code next. The repository is public.

Everything that came from somewhere else

Every sound on this site is a Creative Commons Zero recording from Freesound, which requires no attribution and is credited anyway, with the uploader named and what the recording actually is. The typefaces are Fraunces, Source Serif 4, Caveat and IBM Plex Mono, all under the SIL Open Font License.
