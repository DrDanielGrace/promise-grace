IF YOU TEACH

Every one works from a link, so a class can go straight to a single simulation without wading through a notebook first. Every setting is in the address bar, so the link you copy carries the configuration you set up.

They all have three depths. Picture is what happens with no numbers. Mechanism names the quantities. Maths shows the governing equation with the values live. Pick whichever suits the class.

Every one also has a show the code control that reveals the function actually running it, and under that, a list of what it assumes and where it stops being true. That is there because several of these were wrong the first time. A simulation that will not tell you what it is faking is not teaching anybody anything.

There is one more thing here that is not a simulation: the undergraduate study, walked through, including the parts she would do differently now.
